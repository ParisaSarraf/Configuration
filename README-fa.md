# بازطراحی واکنش‌گرای صفحه مدیریت محصول — بازگشت توضیحات

این بسته شامل تمام فایل‌های src ارسالی شما و تغییرات صفحه اصلی است.
فقط فایل‌های فهرست‌شده در انتهای این راهنما تغییر کرده‌اند؛ سرویس‌ها، مسیرها و صفحات دیگر دست‌نخورده‌اند.

## اصلاح توضیحات در این نسخه
توضیحات محصول از بخش بازشونده خارج شده و در یک کارت مستقل و همیشه‌نمایان قرار دارد: کنار تصویر در دسکتاپ و زیر آن در موبایل و تبلت‌های کوچک.
متن موجود در user_description هنگام ورود بارگذاری می‌شود و ویرایش آن همراه تصویر از همان فرم و مسیر API قبلی ذخیره می‌شود. متن چندخطی حفظ می‌شود و کادر توضیحات با محتوای طولانی رشد می‌کند (تا ۱۸ سطر، سپس اسکرول داخل کادر).
اندازه‌های جمع‌وجور، درخت کوچک و سایر بخش‌ها تغییر نکرده‌اند.

فایل changes.patch در این بسته فقط تفاوت با نسخه src-responsive-compact.zip قبلی را نشان می‌دهد. در صورت استفاده از src کامل، patch را دوباره اعمال نکنید.
فایل‌های تغییرکرده نسبت به نسخه قبلی:
- src/components/ProductUI/product-workspace.css
- src/pages/Introduction/Introduction.jsx
- src/pages/Introduction/components/ProductInfoForm.jsx

۱۴ بررسی در پیش‌نمایش مستقل برای نمایش اولیه توضیحات، بارگذاری متن قبلی، ارسال مقدار و حفظ آن پس از ذخیره، حفظ متن در خطای ذخیره، جابه‌جایی محصول و نبود سرریز افقی در عرض‌های ۳۲۰ تا ۱۴۴۰ پیکسل موفق بود. این آزمون‌ها با callbackهای آزمایشی انجام شده‌اند؛ اتصال واقعی backend همچنان باید در پروژه کامل بررسی شود.

## اصلاحات نسخه جمع‌وجور قبلی
- فاصله‌های صفحه، ارتفاع سربرگ و تب‌ها و اندازه کنترل‌های دسکتاپ کاهش یافته‌اند.
- کارت تصویر از عرض ۴۸۲ به ۴۲۰ پیکسل و فضای آپلود از حدود ۲۶۰ به ۲۱۰ پیکسل کوچک شده است.
- فاصله داخلی ردیف‌های جدول و اندازه کنترل‌های صفحه‌بندی کاهش یافته‌اند.
- درخت محصولات به نمایش قبلی برگشته: عنوان و کد در یک خط، نشانگر وضعیت کوچک، خطوط اتصال و ردیف‌های ۲۴ پیکسلی؛ کارت و برچسب بزرگ وضعیت از درخت حذف شده است.
- جستجو، فیلتر، بارگذاری تنبل زیرشاخه‌ها و منوی راست‌کلیک حفظ شده‌اند.
- کنترل‌های اصلی موبایل همچنان اندازه مناسب لمس دارند.

## استفاده
۱. از نسخه فعلی پروژه نسخه پشتیبان بگیرید یا تغییرات را در یک branch جدید اعمال کنید.
۲. پوشه src این بسته را در ریشه همان پروژه ادغام کنید. package.json، تنظیمات Vite، Tailwind و aliasهای فعلی پروژه را نگه دارید.
۳. از دستورهای نصب و اجرای موجود در package.json خود پروژه استفاده کنید؛ این آرشیو چون فقط src دریافت شده، یک پروژه مستقل قابل نصب نیست.
۴. برای مرور تفاوت‌ها، changes.patch موجود در بسته را بررسی کنید. پس از کپی src، همین patch را دوباره اعمال نکنید.

## ساختار و سازگاری
- React و JSX؛ اجزای تابعی و default export مطابق ساختار فعلی.
- Ant Design، آیکون‌های موجود و Tailwind بدون افزودن وابستگی جدید به کد اصلی.
- CSS اختصاصی با پیشوند pw-، واردشده فقط در MainLayout؛ صفحه‌های مستقل مدیریت تغییر نکرده‌اند.
- Theme محلی با رنگ سبز طرح؛ هوک‌های QueryServises، ProductContext و مسیرهای قبلی حفظ شده‌اند.
- status فعال و غیرفعال مطابق ProductModal واقعی است. وضعیت نامشخص به‌عنوان «بدون وضعیت» نمایش داده می‌شود، نه پیش‌نویس فرضی.

## قابلیت‌ها
- سایدبار دسکتاپ قابل جمع‌شدن و Drawer موبایل با Escape و مدیریت فوکوس.
- تب‌های قابل اسکرول، پیمایش با کلیدهای جهت‌دار و Home/End؛ همه تب‌های قبلی حفظ شده‌اند.
- نمایش نقش‌ها و مجوزهای فعلی در پنجره پروفایل دسترسی.
- جستجوی کد کامل محصول و میان‌بر Ctrl/Cmd+K با همان API جستجوی قبلی؛ جستجوی نام ادعا نشده چون API فعلی فقط full_code می‌گیرد.
- فیلتر وضعیت در درخت دریافت‌شده؛ فیلتر روی داده‌های بارگذاری‌شده اعمال می‌شود و زیرشاخه‌های هنوز دریافت‌نشده را جستجوی سراسری نمی‌کند.
- انتخاب و رهاکردن تصویر JPG/PNG با محدودیت ۵ مگابایت، پیش‌نمایش، لغو انتخاب و آزادکردن object URL.
- توضیحات محصول در کارت مستقل و همیشه‌نمایان قرار گرفته و ارسال تصویر/توضیحات فقط با ذخیره تغییرات انجام می‌شود. حذف تصویر سرور مانند نسخه قبلی، بلافاصله API را فراخوانی می‌کند.
- جدول درختی و باز/جمع‌کردن همه، خروجی CSV قبلی با عنوان اکسل، صفحه‌بندی و اسکرول افقی محدود به جدول.
- شمارنده و صفحه‌بندی جدول تعداد رکوردهای سطح اول API را نشان می‌دهند، نه تمام گره‌های تو در تو.
- حالت‌های بدون محصول، بدون زیرمحصول، بارگذاری و خطا.

## بررسی انجام‌شده و محدودیت‌ها
پیش‌نمایش مستقل با React 18 و Ant Design 5 ساخته شد. داده‌های API، ورود و عملیات سرور در محیط آزمایش شبیه‌سازی شده‌اند و در src تحویلی وجود ندارند.
۲۲ بررسی رابط شامل فیلترها، باز/جمع‌شدن ردیف‌ها، نمایش دسترسی‌ها، ویرایش توضیحات، رد فایل نامعتبر، انتخاب و لغو تصویر، Drawer موبایل، حالت خالی و نبود سرریز افقی صفحه در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل موفق بود.
نمای دسکتاپ، موبایل، پنجره دسترسی، پیش‌نمایش تصویر و حالت خالی بررسی بصری شده‌اند.
Build و lint کل پروژه و اتصال واقعی API قابل تأیید نبودند، چون package.json، تنظیمات build و backend همراه فایل ارسالی نبودند. نسخه واقعی وابستگی‌ها باید در پروژه کامل بررسی شود.
استاندارد کدنویسی جداگانه‌ای دریافت نشده؛ مبنا الگوهای موجود در فایل‌های ارسالی است.
